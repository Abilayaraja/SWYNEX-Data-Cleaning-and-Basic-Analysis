Data Cleaning and Basic Analysis Report

1. Introduction

This project focuses on cleaning and analysing human mitochondrial DNA using basic bioinformatics techniques.

2. Dataset Information

- Organism: Homo sapiens
- Accession Number: NC_012920.1
- Database: NCBI
- Expected sequence length: 16,569 base pairs

3. Objectives

- To obtain a DNA sequence.
- To clean the sequence.
- To count A, T, G and C nucleotides.
- To calculate GC and AT content.
- To save the analysis results.

4. Tools Used

- Python
- NCBI Nucleotide Database
- CSV file format

5. Methodology

The DNA sequence is downloaded from NCBI using its accession number. The sequence is converted into uppercase letters. Valid nucleotide characters are retained. Nucleotide counts and GC and AT percentages are calculated.

6. Expected Output

The project generates nucleotide counts, sequence length, GC content, AT content and a CSV summary.

7. Conclusion

This project demonstrates the use of Python for basic DNA sequence cleaning and analysis. It provides an introduction to computational methods used in bioinformatics.
