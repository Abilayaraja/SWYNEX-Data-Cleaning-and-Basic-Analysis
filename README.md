# SWYNEX-Data-Cleaning-and-Basic-Analysis
Data cleaning and basic analysis of human mitochondrial DNA.
Project Objective

To clean and analyse human mitochondrial DNA using basic bioinformatics methods.

Dataset Details

- Organism: Homo sapiens
- Accession Number: NC_012920.1
- Sequence Length: 16,569 base pairs

Methods

1. DNA sequence cleaning
2. Nucleotide counting
3. GC content calculation
4. AT content calculation
5. Basic data visualization

Expected Results

A cleaned DNA sequence, nucleotide composition summary and GC content analysis.
